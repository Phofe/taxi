# Taxi Moto QR

Prototype pédagogique de gestion de conducteurs de taxi-moto et de présentation de profils via QR code.

## Objectif
- Enregistrer les informations de démonstration d'un conducteur.
- Afficher un profil et un QR code.
- Illustrer le parcours conducteur → QR code → profil public.

## Statut
Prototype portfolio. Il ne s'agit pas d'un service de production : l'authentification, l'API et le stockage sécurisé restent à implémenter.

## Technologies prévues
HTML, CSS, JavaScript, QRCode.js.
